# Shop Apotheke visual references

These screenshots are the authoritative visual references for the prototype. They are sanitized copies of screenshots captured from the current Shop Apotheke experience; personal values were blurred before packaging.

- `01-basket.jpg` — retail header, peach category nav, basket spacing, `Versand durch Shop Apotheke` panel, product row/card proportions.
- `02-checkout-address-form.jpg` — checkout-only header/stepper, form field geometry, error/info blocks, primary CTA proportions.
- `03-checkout-home-selected.jpg` — `An eine Lieferadresse` selected state, radio treatment, address-card geometry, right-side `Weitere Lieferoptionen` card.
- `04-checkout-pickup-selected.jpg` — `An einen Abholort` selected state, pickup CTA and saved pickup-location treatment.
- `05-pickup-station-modal.jpg` — pickup modal structure: top search, filters, station list left, static map-style panel right, bottom selection CTA.
- `06-checkout-carrier-options.jpg` — `Versand` step carrier rows, DHL/Hermes-only pattern, radio alignment, green `Lieferzeitraum`, summary card.
- `07-pdp-postcode-known.jpg` — PDP delivery copy with postcode known, green delivery text, postcode/icon placement, NOW! block position, CTA row.
- `08-pdp-postcode-unknown.jpg` — PDP delivery fallback/location-prompt pattern before precise postcode context.
- `09-email-reference.jpg` — Shop Apotheke email proportions, typography, peach support block, red CTA, secondary lavender app block.

Implementation rule: inspect the relevant screenshot before building or modifying that screen. Do not substitute generic ecommerce patterns. The approved design remains the authority for new behavior; these screenshots are the authority for visual language and existing interaction structure.
